# Peaks Hair Studio — Website

A static, multi-page site (plain HTML/CSS/JS — no build step, no dependencies) so the salon can edit it directly in any text editor. One shared stylesheet (`css/styles.css`) and script (`js/main.js`) are referenced by every page; there is no templating engine, so the header/footer/nav markup is repeated at the top and bottom of each HTML file — edit the same spot in each file to change something sitewide.

## Online booking

A real booking system and owner admin area now live alongside this static
site, in `booking-app/` — a separate Next.js app backed by Supabase
(Postgres + Auth). These 7 pages were not rewritten; copies of them live
inside `booking-app/public/` with a "Book Now" button added to the header,
so the whole thing deploys as one app. See `booking-app/README.md` for setup,
environment variables, local development, and the list of owner decisions
(stylist schedules, service pricing, deposits, policy wording, sender-domain
verification) needed before bookings can go live.

## Preview locally

Open `home.html` directly in a browser, or run a local server from this folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000

## How to update common things

- **Phone, email, Instagram, address**: appears on every page (header nav, footer, and usually the page body) plus the JSON-LD block in each `<head>`. Since there's no shared include, update the value in **all 7 files** — a quick way is to search the whole folder, e.g. `grep -rl "760-449-6456" .`
- **Hours**: edit the `<table class="hours-table">` rows in `visit.html`.
- **Grand opening date**: three places share the date `2026-10-17T16:00:00-07:00` — the `data-event-end` attribute on the homepage banner and preview item in `home.html`, the `data-event-end`/`data-event-passed` attributes in `grand-opening.html`, and the matching check near the top of `js/main.js`. Once that date/time passes, the homepage banner and preview item hide themselves, the "Grand Opening" nav link hides sitewide, and `grand-opening.html` swaps its event details for a short "thank you" message — all automatically, no redesign needed. To remove the page outright, delete `grand-opening.html`, its `<li class="nav-grand-opening">` entry in every page's header, and its row in the homepage preview list.
- **Services / specialties / team bios**: plain text in `services.html` and `team.html`.
- **Current-page nav highlight**: each page's header manually marks its own nav link with `aria-current="page"` (and `home.html`'s logo link does the same for Home) — if you copy a page to make a new one, update that attribute.
- **Colors**: all brand colors are CSS custom properties at the top of `css/styles.css` (`:root { --ivory, --espresso, --copper, --gold, ... }`) — shared by every page.
